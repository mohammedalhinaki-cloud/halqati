# حلقتي — نظام متابعة حلقات القرآن الكريم

تم تحويل الموقع https://01a09567-9516-7937-93de-2765b62f690a.arena.site/ إلى مشروع React + TypeScript + Vite.

## التشغيل
```bash
npm install
npm run dev
```

## المميزات
- إدارة الحلقات والكادر (مالك / مدير / مشرف / معلم)
- إدارة الطلاب مع حفظ سحابي Supabase + تخزين محلي
- تسجيل الحفظ والمراجعة (صغرى/كبرى) والتقديرات والأخطاء والملاحظات
- روابط متابعة لأولياء الأمور مع مشاركة واتساب + تتبع الزيارات
- الخطة السنوية (تواريخ هجرية + أيام التسميع + الإجازات)
- رسوم بيانية لتوزيع التقديرات وتطور الحفظ التراكمي
- ربط Supabase مباشر مع كود SQL جاهز و أدوات رفع/سحب

## Supabase
انسخ كود SQL من تبويب Supabase → SQL Editor وشغّله، ثم أدخل `Project URL` و `anon key` في إعدادات Supabase داخل التطبيق.
